📏 바인딩 소요량 계산

q'ty/pc · height · width · Fabric C/W 를 입력하면 q'ty/YD · q'ty/G.pc · Cons. 가 자동 계산됩니다.

입력

ea
완제품 1장당 필요 수량
inch
바인딩 길이 방향 (예: 0.75 × 3 = 2.25)
inch
바인딩 폭 방향
inch
원단 재단 유효폭

계산 결과

q'ty / YD
—
원단 폭에서 나오는 수
q'ty / G.pc
—
내림 적용 후 완제품 수
Cons.
—
1장당 소요량 (YD)

계산식

q'ty/YD = Fabric C/W ÷ width
—
q'ty/G.pc = 내림(q'ty/YD) ÷ (q'ty/pc)
—
Cons. = height ÷ 36 ÷ (q'ty/G.pc)
—
원단 폭에서 잘리는 조각 수는 정수만 유효하므로 q'ty/YD 에 내림(ROUNDDOWN) 을 적용합니다. 36 은 inch → YD 환산값입니다.
