샘플 작지 종합관리

샘플 의뢰서(PDF)를 올리면 원단 항목별로 펼쳐 정리합니다. 원단 수취 여부·수취일·특이사항을 직접 기록하고 필터로 찾아볼 수 있습니다.
여기에 PDF 를 끌어다 놓으세요
여러 장을 한 번에 올려도 됩니다 · 같은 의뢰번호를 다시 올리면 기록해 둔 수취 정보는 그대로 두고 내용만 갱신합니다
기록은 이 브라우저에만 저장됩니다 (localStorage). 다른 PC·다른 브라우저에서는 보이지 않고, 브라우저 데이터를 지우면 함께 지워집니다. 옮기거나 백업하려면 내보내기로 JSON 을 받아 두세요. PDF 원본은 저장하지 않습니다 — 읽어서 표로 옮기기만 합니다.
