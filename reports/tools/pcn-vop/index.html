Vendor Order Point 검증기

검증파일의 Factory Name + Dept를 기준파일과 대조해 Import Vendor ID와 Import Vendor Order Point의 번호가 정확히 일치하는지 판정합니다.
기준파일 내장 · Vendor_shipping_information 26.08.24 — 행
검증할 파일을 끌어다 놓거나 클릭해서 선택
Item Setup 형식의 .xlsx (예: Cat & Jack Sportswear bottoms & suiting)
검증 로직 (어떻게 옳고/그름을 판정하나)
  1. 검증파일의 각 행에서 Factory Name *와 Dept를 읽습니다.
  2. 기준파일에서 Ship Location Name = Factory Name 이고 Department = Dept 인 행을 찾습니다. (글자가 정확히 같지 않아도 대소문자·구두점 차이는 "근사 매칭"으로 잡아 이름차이로 표시)
  3. 그 기준 행의 Vendor Number = 검증파일의 Import Vendor ID 인지 확인합니다.
  4. 그 기준 행의 Order Specification Number = 검증파일 Import Vendor Order Point 문자열의 맨 끝 숫자 인지 확인합니다. 문자열 내용이 무엇이든 숫자만 정확히 일치하면 정상입니다. (예: D76 San Miguel Petapa Guatemala-7 → 7)
  5. 둘 다 일치 → PASS. 하나라도 불일치 → FAIL. 기준파일에 (Factory+Dept)가 없으면 → NO REF.
모든 처리는 이 브라우저 안에서만 실행됩니다. 업로드한 파일은 외부로 전송되지 않습니다. · 표시 컬럼: Import Vendor ID · Product Description · Apparel Program Name · Vendor Product Description · Manufacturer Style # · Import Vendor Order Point · Import Country of Origin · Port of Export · Factory Name · Factory ID
